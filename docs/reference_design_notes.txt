Chapter 3.SYSTEM DESIGN AND ARCHITECTURE
JalDrishti is designed as an IoT-based water-quality monitoring and early-warning system. The design combines multi-parameter sensing, wireless communication, backend processing, database storage, web monitoring, alerting and proposed image-based screening.
3.1 Project Description
The prototype monitors pH, turbidity, TDS and temperature using an ESP32-S3. Readings are transmitted over Wi-Fi using HTTP/JSON to a Node.js/Express backend, stored in MongoDB and presented through a React web application. Configurable thresholds support automatic alerts and SMS notifications.
3.2 System Architecture
The proposed architecture separates sensing, communication, application, data and presentation responsibilities. This separation provides a clear path from sensor acquisition to processing, storage and user visualization.
3.3 Design Representation
The following nine diagrams describe the proposed system structure, behaviour, data flow, database relationships, software components and deployment. They are design-stage representations for the pre-implementation project.
3.4.1 System Architecture
Description: The proposed JalDrishti system is organized into sensing, communication, application, data and presentation layers. The ESP32-S3 collects pH, turbidity, TDS and temperature readings and sends them through Wi-Fi to the Node.js/Express backend. The backend validates and processes the readings, stores them in MongoDB and supplies the React web application. SMS notification and AI image-screening modules are also connected to the application layer.

Description: The flowchart shows the complete monitoring process. Sensor values are sampled, converted into a JSON payload and transmitted to the backend. The payload is validated before storage. The stored reading is compared with configured thresholds; a breach generates an alert and notification, while normal readings continue to the monitoring dashboard.
